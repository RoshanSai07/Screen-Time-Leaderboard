# Screen Time Leaderboard
A simple web app to track and compare daily screen time. Users can add their screen time and see how they rank against others.

# Features
Add your name and screen time
Automatic ranking from lowest to highest screen time
Data saves in your browser
Delete individual entries or clear all data
Recent entries are highlighted

# How to Use
Open index.html in a web browser
Enter your name and screen time in hours
Click "Add" to see your position on the leaderboard
Use "Delete" buttons to remove specific entries
Use "Clear All" to reset everything

# Files
index.html - Main webpage
styles.css - Styling and layout
script.js - Functionality and data handling

# Note
All data is stored locally in your browser and won't be saved if you clear browser data.

Perfect for digital wellness exhibitions and screen time awareness campaigns!
